Proyecto del curso Teoría de Grafos 2026-II (Universidad del Rosario).
Autores: David Sánchez Lombana, Juan Sebastián Cuesta Montenegro.

## Contenido

- `entrega1/`, `entrega2/`, `entrega-final/` — documentos LaTeX (IEEE) y PDFs de cada entrega.

- `herramienta/` — `critset`, la herramienta en Python (ver [`herramienta/README.md`](herramienta/README.md)), con datos de DeXposure (MIT) y resultados.
